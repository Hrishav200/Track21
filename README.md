Track21 is a beautifully designed iOS app that helps you build and maintain healthy habits through the proven 21-day habit formation method. With an intuitive interface and powerful tracking features, achieving your goals has never been easier.

✨ Features
Current (MVP)

🎨 Beautiful UI - Clean, modern interface with vibrant colors

📅 21-Day Tracking - Visual calendar to track your daily progress

📊 Progress Dashboard - See your completion rate at a glance

🎯 Goal Setting - Set specific goals for each habit

🔔 Smart Reminders - Custom notification times for each habit

🎨 Color Coding - Personalize habits with 6 vibrant colors

💾 Local Storage - Your data is saved securely on your device
